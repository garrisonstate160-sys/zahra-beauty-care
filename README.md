## Local run
1. Install Node.js.
2. Run `npm install`.
3. Set an admin token, e.g. `ADMIN_TOKEN=change-this-to-a-long-random-secret`.
4. Run `npm start`.
5. Open `/` for the public site and `/admin/` for the owner editor.

## Before public production launch
Use HTTPS, a strong secret stored in the host's environment variables, a hosted database/storage service, backups, rate limiting, and proper authentication. The included JSON database is suitable for a small starter/demo and should not be treated as a robust production database.
